# 📝 Full Stack To-Do List App

A clean, responsive and modern full-stack **To-Do List** application built using **React**, **Node.js**, **Express**, and **MongoDB**. This project helps users manage their tasks efficiently — add, edit, mark as completed, delete, and track pending/completed tasks.

---

## 🚀 Features

- ✅ Add new tasks with deadlines  
- 📝 Edit tasks inline  
- ✔️ Mark tasks as completed  
- 📅 View pending and completed tasks separately  
- 🗑 Delete tasks  
- 🖌 Clean, minimal and responsive UI  
- 🔄 Instant updates without refreshing the page

## ⚙️ How to Run the Project Locally

### 🔧 Set Up Backend

```bash
cd backend
npm install
npm run dev
```

### 🔧 Set Up Frontend

```bash
cd frontend
npm install
npm start
```

The frontend will run on http://localhost:3000
The backend runs on http://localhost:5000

### 📌 1. Clone the Repository

```bash
git clone https://github.com/your-username/todo-app.git
cd todo-app
```
